
Welcome to the RSlover521 Minecraft Server!

This server is built around creativity, freedom, transportation systems, and community projects. Players are encouraged to explore, build, and contribute to the world while respecting the creations of others.

## 1. Building and Land Ownership

Players are free to establish a base almost anywhere in the world. Simply find an open location and begin building.

Private builds and personal bases are subject to the server's land tax system. Players are responsible for paying any applicable land taxes associated with their property.

Public community projects are exempt from land taxes. Examples include:

- Museums
- Train stations
- Transit infrastructure
- Community facilities
- Public service buildings

For any projects: permission from the server owner is generally not required before construction begins.

## 2. Schematics and Build Assistance

The use of third-party schematic pasting tools is prohibited.

Examples include:

- Litematica schematic pasting
- Create schematic pasting
- Any mod or software that automatically places blocks without gameplay interaction

However, the use of Create's Schematic Cannon is permitted. Since the Schematic Cannon requires resources, logistics, and in-game construction mechanics, it is considered a legitimate gameplay feature.

For information on using a Schematic Cannon, see [[Create Schematic Cannon Guide]].

## 3. Creative Mode and Materials

The server owner permits the use of creative mode and give commands for obtaining building materials, however, you would have to acknowledge the server owner or any of the server admins in advance before using give commands.

Players may choose to construct projects in either:

- Survival Mode
- Creative Mode

Both playstyles are acceptable.

The focus of the server is on creating interesting builds, infrastructure, and community projects rather than enforcing strict survival progression.

## 4. Griefing and Destruction

The destruction of another player's property is strictly prohibited.

Examples include:

- Destroying a player's base
- Damaging public infrastructure
- Exploding train stations
- Intentionally vandalizing community projects
- Any form of malicious grieving

Violations of this rule may result in an immediate ban.

## 5. Respect Community Projects

Many structures on the server are built for public use.

Examples include:

- Metro systems
- Monorails
- Train stations
- Banks
- Roads and transportation infrastructure

Players should respect these facilities and avoid interfering with their operation.
## 6. No NSFW Content

NSFW (Not Safe For Work) content is prohibited on the server.

This includes, but is not limited to:

- Explicit sexual content
- Pornographic builds
- Inappropriate artwork
- Sexualized structures or decorations
- Other content deemed unsuitable for a general community environment

The server is intended to be welcoming and comfortable for all players.

If you are unsure whether a build or project is appropriate, contact the server owner before proceeding.

Violations may result in administrative action, including removal of the content or player sanctions.

## 7. Rule Changes

Server rules may be updated, expanded, or modified as the server grows.

Players are encouraged to check the wiki periodically for the latest version of the rules.
